# Кинотиндер

Мобильное приложение на Expo: выбираешь фильтры, свайпаешь карточки влево и вправо, собираешь короткий список на вечер. Карточка фильма — описание, трейлер, актёры, режиссёр, сценаристы, композитор, продюсеры; из любого имени можно перейти в фильмографию человека.

Каталог фильмов не хранится в приложении — данные приходят из [The Movie Database (TMDB)](https://www.themoviedb.org/). На устройстве сохраняются только фильтры и свайпы (лайки и дизлайки).

## Стек

- Expo SDK 58, React Native, Expo Router
- Zustand + AsyncStorage
- TanStack Query
- react-native-gesture-handler, Reanimated

## Запуск

```bash
npm install
cp .env.example .env
# В .env подставь EXPO_PUBLIC_TMDB_API_KEY (бесплатный ключ: https://www.themoviedb.org/settings/api)
npm start
```

Открой в Expo Go или симуляторе. После изменения `.env` сервер нужно перезапустить.

## Проверки

```bash
npx tsc --noEmit
npx expo lint
```

## TMDB

Проект использует TMDB API в режиме **некоммерческого** личного использования. В интерфейсе указана атрибуция TMDB. Ключ API не коммить в репозиторий — только в локальный `.env`.

## Лицензия

Код репозитория — по усмотрению автора. Постеры, названия и метаданные фильмов принадлежат правообладателям и поставляются TMDB.
